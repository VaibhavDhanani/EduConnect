# 🎓 EduConnect

> A modern learning platform that seamlessly combines the best of Google Classroom and YouTube functionality

## 📖 Overview

EduConnect is a comprehensive educational platform designed to bridge the gap between teachers and students through an intuitive, feature-rich learning environment. Built with modern web technologies, it provides a streamlined experience for managing classes, assignments, and educational materials.

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** Python, Django
- **Architecture:** Full-stack web application

## ✨ Key Features

### 👨‍🏫 For Teachers

- **Class Management**
  - Create and organize multiple classes
  - Generate unique class codes for easy student enrollment
  
- **Assignment System**
  - Upload and distribute assignments with due dates
  - Track student submissions in real-time
  - Review and grade submitted work
  
- **Content Distribution**
  - Upload educational materials and notes
  - Share resources with entire classes
  - Organize learning materials by topic

### 👨‍🎓 For Students

- **Easy Enrollment**
  - Join classes instantly using class codes
  - Access multiple classes from a single dashboard
  
- **Assignment Management**
  - View all assignments and deadlines
  - Submit work before due dates
  - Track submission status
  
- **Resource Access**
  - Download teacher-uploaded notes and materials
  - Access learning resources anytime, anywhere

## 🚀 Getting Started

### Prerequisites

- Python 3.x
- Django
- Modern web browser

### Installation

```bash
# Clone the repository
git clone https://github.com/VaibhavDhanani/EduConnect.git

# Navigate to project directory
cd educonnect

# Install dependencies
pip install -r requirements.txt

# Run migrations
python manage.py migrate

# Start the development server
python manage.py runserver
```
